# Client

The React client uses Vite for development, production builds, and tests.

## Available scripts

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).
The page reloads when source files change.

### `npm test`

Runs the test suite once.

### `npm run build`

Builds the production app in the `build` folder.
